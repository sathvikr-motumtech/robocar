This site is a personal blog at **https://motumtech.in**. It is a set of static pages: there are
no user accounts, no advertising, no analytics or tracking, and no cookies set by this site.

## What the web server records

The site is hosted by [Hostinger](https://www.hostinger.com/legal/privacy-policy). Like almost
every web host, its servers keep standard access logs — your IP address, the page requested,
the time, and your browser's user-agent string — for security and troubleshooting. I don't use
these logs to identify or profile visitors.

## Comments

Comments on posts use [giscus](https://giscus.app), which stores each comment as a public
discussion in this site's [GitHub repository](https://github.com/sathvikr-motumtech/robocar/discussions).

- Reading comments doesn't require an account. The comment box is loaded from giscus.app,
  so giscus and GitHub receive your IP address and browser details when it loads.
- To post, you sign in with GitHub. Your comment, GitHub username and profile picture are then
  public on GitHub and on this site, under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
  giscus keeps a sign-in token in your browser's local storage until you sign out.
- You can edit or delete your own comments on GitHub at any time.

## Stored in your browser

If you use the light/dark switch, your choice is saved in your browser's local storage so the
site remembers it. It never leaves your device.

## Links to other sites

Posts link to other websites (for example GitHub, Arduino and Raspberry Pi documentation). Those
sites have their own privacy policies.

## Contact

Questions about this policy or a request to remove something: open a discussion on the
[GitHub repository](https://github.com/sathvikr-motumtech/robocar/discussions).
